 Remove an Empty Directory
rmdir directory_name


- Only works if the directory is completely empty.
- Safe and simple.

🧨 Remove a Directory with Contents
rm -r directory_name


- -r stands for recursive, so it deletes all files and subdirectories inside.
- Add -f to force deletion without confirmation:
rm -rf directory_name

⚠️ Be Careful!
- rm -rf / is infamous—it deletes everything. Never run it unless you're absolutely sure.
- You can use ls directory_name first to inspect contents before deleting.
